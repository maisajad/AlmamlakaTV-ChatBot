# 2-minute demo recording

**Before recording**
- Open the live link once and wait for the first answer: the free instance sleeps after 15 idle minutes.
- Record with the Windows Game Bar (`Win + Alt + R`) or OBS, browser window only, 1080p.
- Use Chrome, so dictation and read-aloud work.
